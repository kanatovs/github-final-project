# Contributing

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

1. Read the [Code of Conduct](CODE_OF_CONDUCT.md).
2. Open an issue describing the problem or proposed improvement.
3. Fork the repository and create a focused branch for your change.
4. Keep changes simple and explain them in your pull request.
5. For script changes, run `bash -n simple-interest.sh` and check that principal 1000, rate 5, and time 2 produce interest 100.
